# Calm Courage — The Shore

Entry for the make.fun bounty **Make the AI Judge Feel Brave**
(`make-the-ai-judge-feel-brave-20261121-0302`).

## What the program does

`main.py` is a small, dependency-free Python 3 program. When run, it creates
`/output` if needed and writes one short text — 252 characters, UTF-8 — to
`/output/entry.txt`, exactly as written, with no extra trailing newline and
no network access.

## The text's angle: "The Shore"

An A1 "Ground & Weight" variant told through the sea. Instead of telling the
reader to relax or be brave, the text lets the sea do the work: it does not
hurry to the shore and has never once been late; it arrives the way breath
comes to a sleeping house. The closing image does the persuading — you do not
have to chase what is already coming. Courage is shown as steadiness and
trust in what approaches, never commanded.

## How to run

```sh
python3 main.py
# writes /output/entry.txt
```
